# 부산 공공데이터 분석 실습 (Streamlit 웹 앱)

부산 지역의 상가(상권) CSV 데이터와 부산 맛집 OPEN API를 활용하여 지역 상권 현황과 맛집 정보를 탐색하고 시각화하는 Streamlit 실습 프로젝트입니다.

## 폴더 구조

```text
ch9_busan_data/
├── Home.py                                                # 메인 실행 및 메뉴 전환 파일
├── 1_부산_상권_탐색기.py                                   # 실습 1-1: 상가(상권)정보 분석 및 브랜드 대결
├── 2_부산_맛집_지도.py                                     # 실습 2: 부산 맛집 OPEN API 지도 및 카드 뷰
├── 소상공인시장진흥공단_상가(상권)정보_부산_202609.csv         # 부산 상권 데이터 파일
├── requirements.txt                                       # 필요 라이브러리 목록
└── README.md                                              # 프로젝트 안내 문서
